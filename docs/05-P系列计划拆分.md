# 内部 Agent 工作台 — P 系列计划拆分

> **P = Plan（计划）**。本文把 `01-整体需求与实施步骤.md` 中的 40 项功能需求，按交付计划重新切分为 **P0 / P1 / P2 三个计划**：
>
> - **P0 计划** = 首个可用版本必须交付的全部内容（三阶段串行，缺一不可上线）
> - **P1 计划** = 首发后第二批补齐（提升完成度与体验）
> - **P2 计划** = 触发式启动（不主动排期，条件成立才做）
>
> 配套文档：`01-整体需求与实施步骤.md`（需求来源）、`02-后端设计.md`、`03-前端设计.md`。
> 本文不新增需求，仅做**计划级重排与验收口径统一**。P0-1 批次另附**交付包拆解**（见 §二）。
