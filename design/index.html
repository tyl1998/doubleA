Design Direction · v1 · 2026-09-22

蓝图 工作台

给内部 Agent 工作台一套「工程图纸」的视觉身份：暖纸底上的发丝网格、等宽标注、四角括号与单一靛蓝强调色。 它服务的是长时间驻留的运维与研发——所有装饰都必须回答同一个问题：这条信息是哪个状态、哪一步、谁在跑。

01 / 目的

让「智能体在做什么」可被一眼读出：思考、工具调用、引用、产物、排队与中断，六件事各有自己的视觉位置。

02 / 调性

工业实用（Industrial / Utilitarian）。不混搭：不做霓虹终端，也不做圆角卡片流。

03 / 约束

React 18 + AntD 5 落地（docs/03）；桌面基准 ≥1280px，<1024px 只保证可用； 正文对比度 ≥4.5:1、控件 ≥3:1。

04 / 记忆点

仪表轨 + 序列号：左侧固定的序列栏把"第几屏、什么状态"写成仪器读数；卡片四角括号替代统一圆角阴影。
