# 蓝图工作台 · 前端设计原型

> 这是 **doubuleA 内部 Agent 工作台** 的视觉基准，服务 `docs/03-前端设计.md` 已定稿的 14 条路由。
> 原型是**可直接双击打开的静态 HTML**，不接后端、不进构建、不影响任何验收脚本 —— 落地实现仍按 `docs/03` §六 写在 `frontend/src`。

---

## 一、定调说明（Design Direction Note）

| 项 | 结论 |
|---|---|
| **目的** | 让「智能体正在做什么」可被一眼读出：思考、工具调用、引用、产物、排队、中断六件事各有独立的视觉位置 |
| **受众** | 内部研发 / 运维 / 业务同事，桌面端长时间驻留（基准 ≥1280px） |
| **调性** | **工业实用（Industrial / Utilitarian）· 蓝图工作台**。一个方向，不混搭：不做霓虹终端，也不做圆角卡片流 |
| **记忆点** | ① **左侧仪表轨 + 序列号**：把"第几屏、什么状态"写成仪器读数；② **卡片四角括号**替代"统一圆角 + 统一阴影"的 AI 味卡片脸；③ 暖纸底上的 **8px 蓝图网格**（64px 加重） |
| **字体** | 展示 **Archivo**（工业骨架，700/800）· 正文 **IBM Plex Sans + 思源黑体** · 数据/状态/序列号 **IBM Plex Mono** |
| **配色** | 暖纸底 `#EDEAE3` + 石墨墨 `#17181C` + **单一强调色**蓝图靛蓝 `#1D3FA8`；状态色（成功/中断/失败）另立一套语义令牌 |
| **反默认** | 刻意不用 Inter / Roboto / system-ui 做展示字；不用白底紫蓝渐变；首屏不做"居中标题 + 两个按钮 + 三张卡" |

**为什么敢用蓝色**：被禁的是"白底紫蓝渐变"和"没有主色的平均分配"。这里是一个**有名字的蓝** —— 工程图纸的墨蓝，配暖纸底、发丝网格与等宽标注，全部信息层级由「线 + 字重 + 等宽数字」建立，不靠渐变和阴影撑场面。

## 二、怎么打开

```bash
# 方式一：直接双击（全部资源都是相对路径，file:// 可用）
open design/index.html

# 方式二：本地静态服务（只有一个 Python，无需依赖）
cd design && python3 -m http.server 8090
# 然后访问 http://127.0.0.1:8090/index.html
```

`index.html` 是**设计定调页**：定调说明 + 令牌样张 + 组件八态 + 六屏索引，建议从这里开始看。

## 三、令牌映射（原型 → AntD 5，P0-1-30 落地时按此注入）

原型必须能被实现，否则就是装饰。落地时在 `<ConfigProvider theme={{ token, components }}>` 里做**一一映射**，禁止在页面里写死色值：

| 原型令牌 | 值 | AntD 5 token | 说明 |
|---|---|---|---|
| `--paper` | `#EDEAE3` | `colorBgLayout` | 页底，不用纯白 |
| `--surface` | `#FAF9F5` | `colorBgContainer` / `colorBgElevated` | 卡片、弹窗、抽屉 |
| `--surface-2` | `#F2F0EA` | `colorFillTertiary` / 表头 | 思考块、代码块、表头 |
| `--ink` | `#17181C` | `colorText` / `colorTextHeading` | 正文（16.84:1） |
| `--muted` | `#666A73` | `colorTextSecondary` | 弱化信息（5.15:1） |
| `--rule` / `--rule-strong` | `rgba(23,24,28,.13/.26)` | `colorSplit` / `colorBorderSecondary` | 发丝线与区块界（装饰性） |
| `--rule-control` | `rgba(23,24,28,.5)` | `colorBorder` | **交互控件边界**（实测 3.32:1，满足"控件 ≥3:1"） |
| `--accent` | `#1D3FA8` | `colorPrimary` | 主行动与"运行中"，全站唯一强调色 |
| `--ok` / `--warn` / `--danger` | `#1F6F4A` / `#8A5A00` / `#B3261E` | `colorSuccess` / `colorWarning` / `colorError` | 状态一律「色 + 图形 + 文案」三重表达 |
| `--r-xs/sm/md/lg` | 2 / 4 / 6 / 10 | `borderRadius`(4) / `borderRadiusLG`(6) | 工业感，几乎不圆 |
| `--sh-1/2/3` | Y 偏移 2 / 8 / 24 | `boxShadow` 三档 | 阴影带墨色环境调 |
| `--font-display` / `--font-body` / `--font-mono` | Archivo / IBM Plex (Sans+SC) / IBM Plex Mono | `fontFamily` / `fontFamilyCode` | AntD 默认字体必须被覆盖 |
| `--ease-out` / `--dur-*` | `.16,1,.3,1` / 170·320·640ms | `motionEaseOut` / `motionDuration*` | 与原型同拍 |

> 提醒：AntD 的默认观感（`#1677ff` + 8px 圆角 + 白底）与本方向冲突。**这一步不做，页面会退回"一眼 AntD"**，`docs/06` P0-1-30 的坑预判也要相应加一条。

### 可以亲手点的东西（原型不是截图）

| 位置 | 操作 | 看什么 |
|---|---|---|
| 任意页 | 右上「浅色/暗色」 | 暗色只是令牌覆盖，组件代码一行未动 |
| agents / index | 分段控件切换 **正常 / 加载 / 空 / 错误** | 列表三态与重试入口 |
| chat | 「发送」 | delta 逐字追加 → 思考块自动折叠 → 状态回到 `idle` |
| chat | 「停止」 | 1.2s 收口窗口内已生成内容保留，随后出现 `STOPPED` 标注 |
| chat | 演示组「断线 / 排队 / 确认卡」 | 断线黄条、queued 位次、确认卡锁输入 + 120s 倒计时 |
| chat | 开场白下的引导问题 | 点击**填入**输入框（不直接发送） |
| agents / knowledge / mcp | 「删除」 | 级联删除走弹窗（红色实底 + 明示影响范围）；普通删除走行内确认 |
| mcp | `./mcp.html?serverId=jira` | 自动滚动到分组并高亮（从 Agent 编辑页/失败工具卡直达） |
| 任意页 | Tab 键走查 | 全站可见焦点圈（2px + 2px 偏移），Esc 关浮层 |

## 五、动效规格（Motion Spec）

| 类型 | 实现 | 时长 / 缓动 |
|---|---|---|
| 页面入场 | `.reveal` + IntersectionObserver，6 组错峰 `80ms` | 320ms · `cubic-bezier(.16,1,.3,1)`，只动 opacity + translateY |
| 悬停反馈 | 导航下划线从左扫过；按钮底色加深 + 边框提到墨色；卡片四角括号常驻 | 170ms · ease-out |
| 演示流式 | 等宽点阵加载条 + 方头光标闪烁 + 状态灯脉冲环 | 28ms/字；脉冲 1.6s |
| 场景切换 | 抽屉 640ms 滑入、弹窗 320ms 上浮、Toast 320ms 入 / 320ms 出 | `cubic-bezier(.16,1,.3,1)` |
| 降级 | `@media (prefers-reduced-motion: reduce)` 下全部动效置零，`.reveal` 直接可见 | — |

关键数字：

- **所有页面所有宽度下，文档级水平溢出均为 0 或负值**（负值 = 滚动条占位），即没有元素冲破视口右边界。
- **每页恰好 1 个 h1**，header / main / nav 地标齐备（登录页为独立的 `main` 表单面板，聚焦入口）。
- **触控尺寸在 768px 断点自动生效**：按钮 / 输入框高度抬到 44px，表格改为横向滚动而非被裁掉。
- **按钮最小高度全部 ≥24px**，满足 WCAG 2.2 AA 目标尺寸（触控断点 ≥44px）。

## 八、已知边界（不装成已完成）

- **P1 未画**：`/tasks` 任务中心、`/admin/usage` 用量统计、附件上传（📎，对话页已按 `docs/03` §4.1 标为 P0 隐藏项）。
- **未做真交互**：发消息、上传、检索测试、保存都是本地模拟；`api/` 层、TanStack Query、Zustand 属于 P0-1-30 起的实现工作。
- **中文 webfont**：正文栈是「IBM Plex Sans → Noto Sans SC → PingFang SC / 微软雅黑」。思源黑体在首屏采样时仍在加载（`document.fonts.status = loading`），macOS 上中文字形由 PingFang SC 承接 —— 内部工具用系统中文更省流量，因此**刻意保留这条回退链**，不为了"字体一定要联网"牺牲首屏。
- **窄屏**：设计基准 ≥1280px，`<1024px` 只保证可用（`docs/03` §七）。已在 1024 断点把控件抬到 44px、表格改为横向滚动；375px 下仪表轨转为底部横条。
- **暗色**：令牌层已备好覆盖，但只做到"可用"，没有逐页精修对比度（浅色是交付主态）。
